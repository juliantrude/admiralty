# First version uses Snapshots only, no required mod

The Coach's first version works from save files the Player creates before asking, plus the Timeline inside each Snapshot and the comparison with earlier Snapshots of the same campaign. A Trace mod that logs monthly values would catch crises between saves and also works in games the Player does not host, but any mod that runs script changes the game checksum, so every multiplayer participant would have to install it. Cosmetic UI mods do not change the checksum, but they cannot write data out of the game. Clients can save manually but get no autosave, and the game files offer no setting to enable it.

## Consequences

Numbers between two Snapshots are invisible; only Timeline events (wars, deficits, colonies, perks) survive. The Trace mod stays an option for groups who agree to install it, if real crises turn out to slip through.
